\section*{Purpose}
% ================================================================

This document is the \textbf{test-coverage ledger} for ICNNA (cross-cutting
thread~T.11, adopted at v1.4.2). It enumerates every ICNNA class against its
unit-test status and is updated at each sub-release.

The ledger provides \emph{visibility}: a single place to see what is covered
and what is not. Coverage is enforced by two exit criteria:

\begin{itemize}
    \item \textbf{v1.8.0} (\texttt{oo/} removal sweep): no \texttt{oo/}-derived
          class may be deleted while its modern replacement carries status
          \statusNone.
    \item \textbf{v2.0.0} (release): zero classes at status \statusNone.
\end{itemize}

The governing principle is P2: every class modernised from v1.4.2 onwards
ships with tests. The ledger extends this guarantee to classes not yet
scheduled for a modernisation sub-release.

% ================================================================
\section*{Status Legend}
% ================================================================

\begin{description}[leftmargin=3cm, labelwidth=2.5cm]
    \item[\statusNone]    No unit-test file exists for this class.
    \item[\statusPartial] A test file exists but coverage is incomplete
                          (some properties, methods, or edge cases untested).
    \item[\statusComplete]The test file covers all properties, key methods,
                          and critical edge cases.
\end{description}
